# Ponytail

Ponytail은 프로젝트에 종속되지 않는 에이전트 코딩 하네스입니다. 항상
활성화되는 엔지니어링 규칙, 선택 가능한 코드 압축 단계, 재사용 가능한
전문 스킬을 제공합니다.

최신 설치, 구성, 개발 문서는 [기본 README](README.md)를 참조하십시오.
