# Ponytail

Ponytail es un arnés agnóstico para agentes de programación. Combina reglas de
ingeniería siempre activas, niveles opcionales de compactación y habilidades
reutilizables especializadas.

La documentación vigente de instalación, configuración y desarrollo está en
el [README principal](README.md).
