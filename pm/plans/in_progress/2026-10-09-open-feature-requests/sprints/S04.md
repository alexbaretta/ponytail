## Intent and acceptance

Migrate every repository-owned authored JS source to strict TypeScript with
complete compiler/TSTS coverage. Generated runtime JS remains supported.
Preserve CLI/hooks/installers/packages/adapters and independently invoked
benchmarks. Prevent authored-JS regression; final acceptance covers all issues.

## Required planning deliverables

Inventory final handwritten/generated sources and every execution/packaging/
installation/test/generator consumer. Order compiler/build/manifest foundations,
core runtime/scripts/tests, skill tooling/host adapters, package subprojects and
isolated benchmarks, then inventory enforcement and final proof. Freeze strict
projects, compiled artifact ownership, selected commands, atomic migrations,
generated-source mappings and exact path dependencies. S01-S03 must complete
before shared-path migration. Decompose into additional serialized sprints if
atomic review exceeds plan-execution limits; never hide migration in one tasklet.
Discover additional owned directories before paths freeze.

## Scope, exclusions and questions

Root repository only, including every JS subtree and its consumer configuration.
Exclude behavior redesign, weakened typing, duplicate test contracts, new cloud
topology, client edits and benchmark provisioning from core commands. Apply
static-type-safety and TypeScript testing skills during detailed work.
No additional product choice identified; compilation and migration mechanics
remain agent-owned planning. Final-tree full tests, TSTS, installer, adapter,
traceability/version and source-inventory evidence are pending.
