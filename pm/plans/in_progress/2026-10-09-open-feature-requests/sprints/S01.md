## Frozen implementation batch

Existing immutable `parse_result_v1` is the checkpoint; no physical schema
change is needed. Commit validated cache rows in batches (default 10, positive
`--batch-size`). A session advisory lock on the existing project/repository/
worktree/corpus key spans all transactions. Publish generation/file/entity/
relationship/search rows and the pointer in one final transaction. Recollect
inputs immediately before commit and reject changed HEAD/content/config/parser
identities. Retain old published data and compatible cache on failure.
