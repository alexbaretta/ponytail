## Questions

### [OPEN] Q01: Initial Repository Inventory

Identify the canonical governed repository roots to configure. Configure each
repository once; do not separately configure worktrees that inherit the same
tracked project files.

### [OPEN] Q02: Target Inventory Per Repository

For each repository, confirm:

- every buildable target and implementation language;
- every available bundled adapter;
- the exact `tsconfig` used by each TypeScript build;
- the custom adapter command for each unsupported language or build system;
- the smallest target-specific build command;
- additional files consumed by each build; and
- documentation, test, environment, infrastructure, and management paths
  that do not participate in the target.
